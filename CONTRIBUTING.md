# Contributing to Rustfire

Thanks for helping improve Rustfire. The project is still working toward compatibility with [ONCE Campfire at commit `91d294f`](https://github.com/basecamp/once-campfire/commit/91d294f4a09f9bbe37f9548959bfcb43645678fb).

## Reporting issues

Open a GitHub issue with the Rustfire revision, steps to reproduce, expected behavior, and actual behavior. For a compatibility mismatch, include the corresponding Campfire result when possible. Remove account data, credentials, and private messages from logs and fixtures before posting them.

## Pull requests

Keep changes focused and explain the behavior they fix. Add a paired probe when a Campfire mismatch can be reproduced, and run the relevant checks described in the [README](README.md#development-and-verification). Performance changes should include the exact workload and paired results, including failures and limitations.

Please keep upstream copyright and license notices with copied assets or source material. Contributions to Rustfire are submitted under the repository's [MIT license](LICENSE).
